# Donate4Life

This is a program that was build using double linked list concept to search and sort records of donation.

These are the methods in the program:

•	Add new record:
The records are inserted in a sorted order based on a string field.

•	Delete record:
o	The record is deleted by the string field.

•	Search record:
o	A search can be done on the string field.

•	View all records:
o	Display all the records
